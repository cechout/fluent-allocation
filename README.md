a simple app to assign students to their courses based on their individual priority list and the respective course

install instructions for the .exe file:

1. Download and install SQLLocalDB.msi 2019/2022
2. Download and install the Kurszuteilung Setup.msi file.

perhaps this is needed too:

3. Open the folder where the program was installed.
4. Navigate to Datebase > select main_database4.mdf > right click > properties > security
5. give every user "full control" permissions

the .exe can now be started
